### 关于我

铭心，一枚游走在代码、服务器和各种奇怪想法之间的互联网小牛马。

常用 **PHP、Go、Python 和 Shell**，喜欢把脑海里的想法做成能用的东西。写工具、搭服务，也在把博客做成一场游戏。只要还有人在用，就继续折腾。

Codex 配额充足时，是无所不能的天才程序员；配额耗尽后，当场陨落，只会写 Hello, World!
